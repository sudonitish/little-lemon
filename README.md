# Little Lemon

A restaurant website built as part of the Meta Front-End Developer Coursera course.

## Features

- Restaurant website with modern design
- Responsive layout
- Table reservation system
- Menu display
- Contact information

## Technologies Used

- HTML5
- CSS3
- JavaScript
- React

## Installation

1. Clone the repository
```bash
git clone https://github.com/sudonitish/little-lemon.git
```

2. Navigate to the project directory
```bash
cd little-lemon
```

3. Install dependencies
```bash
npm install
```

4. Start the development server
```bash
npm start
```
